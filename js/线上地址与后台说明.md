# 线上地址与后台说明（打进澳网 / tennis-log）

## 线上地址（给用户访问）
- 正式地址：**https://susustarrrrrr.github.io/tennis-log/**
- 部署方式：GitHub Pages（仓库 `susustarrrrrr/tennis-log`，分支 `main`，根目录 `/`）
- 改完代码 `git push` 到 `main` 后，GitHub Pages 约 1 分钟自动更新。

## 后台（数据存在这里，不在网页文件里）
- 所有打球记录、运动类型都存在 **Supabase 云端数据库**，由 `js/config.js` 里的
  `SUPABASE_URL` / `SUPABASE_ANON_KEY` 指定。
- 这两个值是官方要求放在前端的**公开值**（publishable / anon key），已预填好，一般无需改动。
  具体位置与更换方法见 `js/config.js` 与 README 第 ⑤ 步。
- 想换自己的后台：直接改 `js/config.js`，或在 App 登录页底部「数据库连接设置」临时覆盖（仅存本机）。

## 关于历史记录 / 多链接共用
- 本 App 的数据在 Supabase，网页只是「访问入口」，所以换前端地址不会丢数据。
- 旧链接 `agentos-app.net` 与新链接 `github.io/tennis-log` 指向**同一个 Supabase 项目**，
  历史记录互通、**无需迁移**——用原来的账号登录即可看到全部数据。
- 若想彻底只用新链接：去 agentos-app.net 平台把旧部署下线即可（两个前端相互独立，互不影响）。

## 故障自查
- 登录报「数据表还没建好」：在 Supabase 控制台重跑 `supabase/schema.sql`。
- 完全打不开 / 空白：先确认 GitHub Pages 构建状态为 `built`（仓库 Settings → Pages）。
